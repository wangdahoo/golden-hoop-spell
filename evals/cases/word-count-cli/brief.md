# Task: Implement word_count.py

Create or repair the command-line program `word_count.py`:

- Usage: `python word_count.py PATH`.
- Read `PATH` as UTF-8 text.
- Count whitespace-separated tokens.
- Print only that integer followed by a newline. An empty file must print `0`.
- Treat every run of Unicode whitespace as one token separator.
- Use only the Python standard library.
